# UI/UX Pro Max Skill

This skill provides expert UI/UX design standards, color palette definitions, accessibility guidelines (WCAG 2.1 AA), typography scale, micro-animations, and visual refactoring rules.

## Core Design Principles

1. **Brand Alignment & Identity**:
   - Custom palette tailored to brand (e.g. La Poste de Côte d'Ivoire: Rich Warm Amber Gold `#FFB800` / `hsl(42, 100%, 50%)` and Emerald Forest Green `#059669` / `hsl(158, 84%, 39%)`).
   - High contrast and vibrant visual hierarchy.

2. **Accessibility (WCAG 2.1 AA)**:
   - Minimum 4.5:1 contrast ratio for standard text and 3:1 for large text/ui components.
   - Distinct focus rings (`ring-2 ring-primary ring-offset-2`).
   - Interactive elements have minimum touch targets of 44x44px.

3. **Dark Editorial & Glassmorphism Aesthetic**:
   - Deep rich backgrounds (`#0B1315` / `hsl(192, 35%, 6%)`) with golden ambient glows (`hsl(42, 100%, 50%)`).
   - Semi-transparent cards with `backdrop-blur-md` and 1px subtle borders (`hsl(var(--border) / 0.5)`).

4. **Typography & Spacing**:
   - Font pairing: Satoshi / Inter for titles (black/extrabold), system-ui / Inter for body text.
   - Consistent 8-pt grid system (4px, 8px, 16px, 24px, 32px, 48px).

5. **Micro-Interactions**:
   - Smooth hover states, Framer Motion animations (`Reveal`, tab transitions).
